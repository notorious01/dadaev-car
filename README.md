# Dadaev Car — прототип Telegram Mini App

Кликабельный прототип приложения проката автомобилей Dadaev Car (Махачкала):
каталог, бронирование по датам, заявки, шахматка и автопарк для менеджера.

Данные демонстрационные: машины и цены взяты с Яндекс Карт, условия аренды предварительные.
Состояние хранится в браузере (localStorage), сервера и базы пока нет.
